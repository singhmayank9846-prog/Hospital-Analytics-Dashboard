Hospital Analytics Dashboard  Created by Mayank Singh

PROJECT OVERVIEW

This project is based on a 1000-patient hospital dataset.
I cleaned the data, created pivot tables, and designed an interactive Excel dashboard to analyze patient details, treatment duration, conditions, and medicines.

Files in This Project

Hospital 1000 Patient Database By Mayank_singh.xlsx – Final cleaned file with dashboard
real_drug_dataset.csv – Raw drug dataset
raw_data folder – All original raw data files

What This Dashboard Shows
Total number of patients
Male vs Female comparison
Most common health conditions
Most used medicines
Average dosage
Average treatment duration
Slicers to filter by gender.

Tools Used
Microsoft Excel
Pivot Tables
Pivot Charts
Slicers
Basic data cleaning

Summary

This project helps in understanding patient trends and hospital treatment patterns in a simple and clear way.
